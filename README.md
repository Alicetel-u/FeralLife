# けもの荘 ～クズ住人観察記～

共同開発は [日本語マニュアル](docs/collaboration.md) と [Codex向けルール](AGENTS.md) を参照してください。各PCの初回設定は `powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup-collaboration.ps1` で行います。

**プロジェクト全体の仕様・現在の実装・未実装・他AIへの引き継ぎは [PROJECT.md](PROJECT.md) にまとめています。** Grokなどに渡す場合は、まずこのファイルを読ませてください。キャラの見た目は [docs/character-style.md](docs/character-style.md) を参照してください。

Windows / PCブラウザ向けの、2Dリアルタイム獣人生活観察ゲームの試作です。外部生成AIや追加パッケージを使わず、住人の欲求・性格・時間帯で行動を決めます。

## 起動

**`起動.cmd` または `play.html` をダブルクリックしてください。** 単体HTML版は画像・CSS・JavaScriptをすべて内蔵しており、インストール・Node.js・ネット接続は不要です。Edge / ChromeなどのPCブラウザで遊べます。

開発用の分割ソースを使う場合は、Node.jsで `npm start` を実行し、`http://localhost:4173` を開きます。`index.html` はHTTPサーバー経由で開きます。変更後は `npm run build` で単体版 `play.html` を更新します。

## 遊び方

- 最初は101号室の猫「灰田 モク」を大きく表示。「全体を見る」で6部屋を一覧。「大きく見る」で1部屋に寄ります。下の6部屋ボタンで対象を選べます。
- 内装は家具と室内生活、外観は建物・共用廊下・階段・通りを観察。「住人を追う ON」は、外出時に外観、帰宅時に内装へ自動で切り替えます。手動で表示や大きさを変えると追跡はOFFになります。
- 1920×1080を基準に16:9で自動スケーリング。⛶ボタンはFullscreen APIで全画面を切り替えます。ドット絵は補間を切って表示します。利用環境によって全画面が使えない場合はブラウザのF11キーも使えます。
- 住人ノートは必要なときだけ開く引き出し式。開いていても生活は進みます。日誌やイベント詳細を開くと時間が止まります。
- 時間は自動進行。10秒＝ゲーム内1時間。1×・3×・6×と一時停止に対応しています。
- 3日目の9時に初回募集、その後は原則3日ごと。封筒をクリックし、候補2人から1人を迎えます。満室になると募集は止まります。
- 出来事をクリックすると背景と影響を読めます。詳細・申込書・日誌を開いている間は時間が止まります。
- 18日目の9時に、関係・借金・ゴミ・入居数から5種類の結末のいずれかが決まります。
- 「はじめから」で別の組み合わせを試せます。Spaceキーでも一時停止できます。
- データはブラウザのlocalStorageへ5秒ごと、選択時、ページを離れる時に保存されます。閉じている間や非表示のタブでは時間は進みません。データは同じURL・同じブラウザの中だけに保存されます。単体版と開発サーバー版の保存は別です。ブラウザがローカルファイルの保存を許可しない場合はヘッダーに「保存できません」と表示されます。

衛生状態は高いほど良好、それ以外の欲求は高いほど満たす必要があります。喫煙・飲酒は架空の成人獣人の生活を描くデフォルメ表現です。

## 実装

- `src/simulation.js`：独立したシミュレーション。欲求の時間変化、行動スコア、クールダウン、交流・口論、家賃、候補、結末。
- `src/renderer.js`：1920×1080 Canvas、内装の1部屋／6部屋、外観の追跡／全体、家具、喫煙・睡眠・昼夜の照明。
- `src/movement.js`：共通座標で室内・廊下・階段・通りの経路、画面外の外出、同じ経路で帰宅。絶対時刻で補間し、表示切り替えや保存復元でも位置が連続します。
- `src/app.js`：観察ノート、日誌、2択、モーダル中の一時停止、自動保存、任意の環境音。
- `assets/apartments.png`：ユーザー提供の参考画像を背景に使用。
- `assets/characters/cat/`：ユーザー提供のタバコ猫を透過した素材。ゲーム内と住人ノートに採用。`src/character-art.js` で管理。
- `docs/character-style.md`：今後のキャラの見た目・素材サイズ・差分の方針。

猫は基本立ち絵1枚を採用し、上下揺れ・左右反転・睡眠時の簡略回転で表示します。専用の行動ポーズは未作成。その他の住人は原稿が届くまで仮スプライトを使用します。

家賃は試作向けに1人1日1,200円として処理します。未払い分は借金へ加算。職業ごとの日収を毎朝計上します。入居候補は選んだ人物だけを候補プールから除き、選ばなかった人物は後の募集にも現れます。各住人に一日一回の外出予定を設定。上階の住人は階段を下り、街路の端から画面外へ消え、一定時間後に逆の経路で戻ります。外出による室内行動の減少に合わせ、借金の結末条件は合計60,000円超、ゴミの結末条件は平均40超へ調整しています。移動は廊下と階段を通る簡略補間で、衝突判定・本格的な経路探索はありません。Windowsネイティブ実行ファイル・クラウド保存・外部AIは未実装です。

## 検証

`npm test` で初期状態、募集時刻、2択の検証、満室、欲求の範囲、20シードでの結末までの進行、保存復元、関係、観察のみのプレイ、100シードでの結末の分岐、単体版の内蔵ファイルとスクリプト構文を確認します。追加で階段経路・画面外への外出と帰宅・訪問・移動途中の保存復元・旧セーブ互換を検証します。開発サーバーの `/tests/visual.html` は実セーブを使わないカメラ検証用です。
