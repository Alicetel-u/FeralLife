# ローカル音声生成

台詞は既存のゲームモジュールから抽出する。本文、画像、BGM、セーブ形式は変更しない。

全体生成・読み修正の前に `docs/voice-failures.md` と `config/voice-pronunciation-issues.json` を確認する。ドライランは要注意語の正しい読みと該当箇所を自動表示する。読み指定は生成入力のかな置換に適用し、表示本文は維持する。登録後も生成済みMP3は自動では変わらない。

1. `npm run voice:setup` をターミナルで実行し、非表示の入力欄にAPIキーを貼り付ける。
2. `npm run voice:verify` は Voice ID・日本語モデル・実残高をGETで確認する。音声は生成しない。
3. `npm run voice:plan` は通信なしのドライラン。話者・演技・文字数・設定・推定消費量は `.local/voice-plan.json` にも保存する。
4. 対象と消費量をユーザーに提示し、本番生成の承認を得る。
5. 承認後のみ `node tools/voices.mjs --generate --approve=<planId>` を実行する。現在の計画ハッシュが一致する場合のみ送信可能。第一幕のモク全体は `--scope=act1 --speaker=cat` を計画・生成の両方に指定する。大家と第二幕全体の一括生成は許可しない。
6. `npm run build` でマニフェストを反映する。生成MP3と `src/voice-manifest.js` を一緒に配布する。音声は発話時のみ読み込む。play.html単体を移動した場合もassets/voicesを隣に置く。

キーは `.local/elevenlabs.json` に平文でローカル保存される。共有PCではOSアカウントのアクセス権で保護する。`.local/` 全体はGit対象外で、ローカルHTTPサーバーも配信しない。公開ビルドにはソースJS・表示用アセットだけを含める。削除する場合はこのファイルを削除し、失効はElevenLabsのAPIキー管理画面で行う。キーをチャットやログに貼らない。

`--scope=act1 --speaker=cat` は第一幕のモクだけを抽出・生成する。選択肢の全分岐、エピローグ、周回と日常の移動・独り言を既存ゲームの状態遷移から抽出する。`--scope=act1`（話者指定なし）、`--scope=act2`、`--scope=all` は抽出確認専用で、一括生成は拒否する。将来の追加は同じextractorに幕のデータソースを登録する。

## 演技

Eleven v3の公式に対応する音声タグとvoice_settingsを使用する。設定は `config/voice-performance.json`。directionは人間向けの指示で、APIの自由文演技指示フィールドではない。本文は変更せず、生成要求のみにタグを前置する。通常・心の声・ツッコミは別設定と別キャッシュ。ツッコミを感嘆符や画像の怒り表情から分類しない。内省は既存のinnerVoiceフラグとプロローグの話者ラベルで判定する。

公式仕様: https://elevenlabs.io/docs/api-reference/text-to-speech/convert
音声タグ: https://elevenlabs.io/docs/help-center/product/core-capabilities/text-to-speech/how-do-audio-tags-work-with-eleven-v3-and-v4

モデル対応タグでも演技・発音は確率的で、読み上げられない保証はできない。生成後に試聴し、タグの発音・威圧的な演技・「ニャ」の発音を確認する。問題があれば設定修正で別キャッシュ候補にし、再生成の承認を得る。

クレジット推定は入力文字数（タグを含む）×設定単価であり、契約・モデルの実請求とは異なる可能性がある。実残高はGET /user/subscriptionから別表示する。生成前後の差分も同一アカウントの別用途の消費を含み得る。

## 再開

成功音声は毎回マニフェストに保存する。既存MP3を再利用し、自動再試行はしない。送信前に `.local/voice-journal.json` にintentを書き込む。失敗・中断の記録があるクリップは停止し、ElevenLabsの履歴で請求と生成物を照合する。取得済み音声を対応ハッシュのMP3へ復元すれば再利用できる。未生成と確認できた記録だけを手動解除する。ロックファイルは並列生成を拒否する。異常終了で残ったロックも、自分が起動した生成が終了済みと確認してから解除する。

ゲーム内は会話MENUでボイスON/OFF・音量を調整する。次へ・戻る・SKIP・画面終了で音声を停止し、AUTOは通常の表示待ち時間と再生終了の両方を待つ。未生成・読み込み失敗・自動再生拒否時は従来のテキスト進行を維持する。


## 初回生成の記録と試聴フィードバック

承認済み序盤29本を生成。全29本のMP3デコード成功、総時間125.68秒。生成前後の残高差は52だが、リクエストのcharacter-costヘッダー合計は390で、残高の反映遅延等を含め実請求額は未確定。残高差を確定消費量として扱わない。

ユーザー試聴で「サイトで作ったものより棒読み」との評価があり、演技品質は未合格。現在の音声は比較用として保持し、追加生成は停止。心の声のstability=1は表情を抑える可能性があり、静かな演技と単調な演技を混同しない。directionは人間向けメモで、生成リクエストには渡らない。サイトの好みの履歴とモデル・設定・入力を照合してから少数サンプルで再調整する。

会話の補助ツールバーは既存CSSで非表示のため、歯車のボイス・会話設定ボタンを追加。設定内から音量・ON/OFF・AUTO・SKIPを操作する。

`--pronunciation-only` は序盤の読み指定語を含むセリフだけを抽出する。生成入力の置換後テキストをキャッシュに含めるため、同じ補正済み音声は再利用できる。`.local/voice-plan.json` の `spokenInput` で生成入力も確認できる。

Voice ID設定は既存の `characters.<id>.voiceId` 形式と簡易の `<id>: voiceId` 形式に対応する。モクはユーザー確定の `0ptCJp0xgdabdcpVtCB5`。大家の新規生成は保留。
