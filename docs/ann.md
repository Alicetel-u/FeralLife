# 蜜野 アンと金満 トクゾウ

アンは27歳の猫獣人。在宅の文字起こしをしながら、けもの荘で一人暮らしする。
既婚の会社役員トクゾウ（56歳）の愛人。約束と援助を待つ日常を会話で描く。

- 新住人 `ann` として入居候補へ追加。古い進行中セーブにも候補を追加。
- 日収1000円。買い物を好む。16時から約3時間、喫茶店へ外出。
- 3の倍数の日の外出で `journey.companion = patron` を付け、生活費の援助6000円と固有イベントを記録。
- トクゾウは街路でアンと合流して並んで歩く。外観モードで見える。部屋・廊下・階段・画面外・帰宅時には表示しない。
- トクゾウは入居候補にも住人配列にも追加しない。アンは別の部屋に一人で住み、一人で帰る。
- 経路の同行情報はセーブに保存する。`?preview=ann` は二人が街路にいる時点を一時停止で表示し、既存セーブを読み書きしない。

素材は `assets/characters/ann/idle.png` と `assets/characters/patron/idle.png`。
組み込みimagegenで実際のアルファ透過を作成。加工プロンプト: 白背景と隙間のみを透過し、元のキャラ・顔・ポーズ・衣装・小物・ピクセル表現を保持。白い服は残し、おじさんの葉巻の煙も残す。追加物・影・文字なし。生成編集のため原稿との完全なピクセル一致は保証しない。
