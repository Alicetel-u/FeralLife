# 第一幕・第二幕のボイス補完

既存収録を保持し、大家・モク・ルナの不足音声だけを ElevenLabs eleven_v3 で追加。
ナレーションと謎の声は対象外。表示セリフ、ストーリー、セーブ形式は変更しない。

承認済みの3人の試聴と同じ `duel-manager` / `duel-moku` / `duel-luna` プロファイルを使用。
音声の検索キーは元の場面・演技キーを維持し、生成時の演技指定を `deliveryProfile` に記録する。
立ち絵パートではミニゲーム専用の追加加速を適用せず、収録した速度で再生する。

`node tools/voices.mjs --scope=missing --quiet` で不足分を確認できる。
生成には出力された計画ハッシュの承認指定が必要。既存ファイルと生成ジャーナルを確認し、
通信失敗や不明な生成履歴を自動で再試行しない。APIキーとジャーナルは `.local/` 内だけに保存。

`tests/voice-coverage.test.mjs` は両幕の選択肢・BAD END・巻き戻し・エピローグ、生活中の会話と
独り言について、実際の再生キーに対応する音声ファイルが存在することを検証する。
