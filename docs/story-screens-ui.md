# タイトル・結果画面のデザイン

`src/story-screens.js` の `storyScreenHTML()` を `openModal()` で適用する。
対象はメインタイトル、各幕タイトル、バッドエンド、幕クリア、次章案内、火災・売却・差押え・巻き戻しの画面。
通常会話、トラブル回避、第二幕の映像オープニング、初回悲劇の白画面は装飾対象から除外する。

- 色：赤 `#ed2448`、黒 `#111116`、紙色 `#fff5e7`。
- 人物は既存のバストアップを使用。ルナの幕タイトルも `busts/hostess-neutral.png` を明示する。
- 見出しと人物を左右に配置し、スマホ幅では人物を上、本文と操作を下に配置する。
- 長文画面は `#modal-content` 内で縦スクロールし、復帰ボタンまで操作できる。
- 装飾は入力を遮らず、既存の `data-*` 操作、セーブ形式、音声、演出タイマーを維持する。
- 画面切り替えは有限のワイプ。動きを減らす設定では装飾アニメーションを止める。

CSS は `styles.css` の `Story screens, edition 02` ブロックと関連する `showcase-*` セレクター。
`tests/story-screens.test.mjs` で対象画面・操作要素・対象外画面の維持を確認する。
