# 大家のミニキャラ

## 現在の素材

観察画面は `assets/characters/manager/matched-v3/` のセットを使用する。デザイン基準は新しい通常表情 `new-poses/emotions/neutral.png`。白黒の髪、渦巻き目と目の下のクマ、茶色のセーター、黒いズボンと靴を共通にし、日常動作・掃除・歩行を同じデザインで生成した。既存の同デザインの感情差分も、このセットの枠へまとめている。

旧160px素材、旧 `new-poses/daily/`、前回の `clean-v2.png` は観察画面で使用しない。旧表情シート `emotions-v1.png` も大家用には読み込まず、描画しない。対決専用の大きな身振りは `new-poses/act2-battle/` の専用素材を使う。

`python tools/prepare-manager-matched-art.py` で原稿から再構成できる。透過RGBA、512×512、足元原点256,492。立ち姿の人物高は455px、観察画面での身長はモクと同程度。ポーズごとの倍率を実行時に切り替えない。座り・寝姿は立ち姿と同じ頭の大きさを保ち、全体を立ち姿の高さに引き伸ばさない。ホウキの先を人物の足元として扱わない。

原稿と生成指示は `matched-v3/sources/`、枠・原点・整形倍率の記録は `matched-v3/asset.json`。原稿はゲームの公開パッケージに含めない。古い整形ツール `prepare-manager-art.py` は旧素材向けなので、現在のセットの更新には使用しない。

## 歩行と切り替え

歩行は独立した2枚ではなく、同一の参照から生成した4コマ `walk_a → walk_pass_a → walk_b → walk_pass_b`。頭・胴体・カメラ方向・足元の登録を揃え、全4コマを同じ倍率で枠へ配置する。実際に移動した距離20ごとにコマを進める。画面のフレームレートや全体の経過時間では足運びを変更しない。一時停止時は位置・歩行距離・コマが停止し、進行方向に向く。掃除は別々のA/Bを使い、会話中には掃除を止める。

大家は表示専用で、住人の家賃・欲求・募集人数・通常セーブの構造に追加しない。廊下への移動は建物右の出入口を経由する。観察中の声は本人の頭上に接続する。会話画面の既存メッセージウィンドウや住人の立ち絵は変更しない。

`?preview=manager&pose=walk_a` などで通常セーブとは独立した確認ができる。新しいポーズを追加するときは静止画単体の印象だけで判断せず、通常・掃除・全歩行コマ・会話時の全表情を同じ画面倍率で切り替えて確認する。
