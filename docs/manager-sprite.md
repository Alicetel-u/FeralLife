# 大家のミニキャラ

採用デザイン：人間、若めの顔、少しふっくらした体形、黒の混じった白髪のオールバック、茶色のセーター。サングラスを外し、クレヨンでぐるぐる描いたような目と目の下のクマで、コミカルに疲れた顔を表現する。全8ポーズでこの目を共通にし、眉・口・身振りで感情を区別する。

`assets/characters/manager` に通常、歩行A/B、掃除A/B、喜び、怒り、落ち込み、驚き、ツッコミの10ポーズを保存。内蔵ImageGenで生成し、原稿は `sources`、プロンプトは `generation-prompts.md` に保存。`python tools/prepare-manager-art.py` は原稿を透過PNG・160×160・足元80,156のゲーム用フレームへ整える。移動中は歩行A/Bを交互に表示し、移動方向を向く。一時停止中は歩行コマも停止する。

`src/manager-life.js` は表示専用。大家は入居者配列・家賃・欲求・募集人数に加えず、通常は建物前で掃除する。外・1階廊下に住人がいれば向き合い、掃除を止める。廊下への移動は建物右の出入口を経由する。ポーズ切替と移動は停止操作に従い、セーブの構造を変更しない。

観察中の大家の声は本人の頭上の吹き出しに接続する。大家のミニキャラは観察画面専用。会話画面では大家の立ち絵を現在表示せず、名前とセリフを表示する。住人2人の会話では住人の立ち絵・表情を保持する。感嘆符だけで怒りにはしない。音声生成・既存セリフの変更は行わない。

`?preview=manager` は通常セーブと独立した表示確認。`&pose=happy` 等でポーズを指定できる。一時停止を解除すると掃除アニメーションを確認できる。

掃除姿は `new-poses/daily/clean-v2.png` を使用。通常姿と顔・頭身・描線を合わせ、髪から靴底まで420px、足元原点256.5,474で揃える。ホウキを含む全体の高さでは人物を縮小しない。
