# 大家のミニキャラ

採用デザイン：人間、若めの顔、少しふっくらした体形、黒の混じった白髪のオールバック、サングラス、茶色のセーター。

`assets/characters/manager` に通常、掃除A/B、喜び、怒り、落ち込み、驚き、ツッコミの8ポーズを保存。内蔵ImageGenで生成し、原稿は `sources`、プロンプトは `generation-prompts.md` に保存。`python tools/prepare-manager-art.py` は原稿を透過PNG・160×160・足元80,156のゲーム用フレームへ整える。

`src/manager-life.js` は表示専用。大家は入居者配列・家賃・欲求・募集人数に加えず、通常は建物前で掃除する。外・1階廊下に住人がいれば向き合い、掃除を止める。廊下への移動は建物右の出入口を経由する。ポーズ切替と移動は停止操作に従い、セーブの構造を変更しない。

観察中の大家の声は本人の頭上の吹き出しに接続する。会話画面でも感情に応じたミニキャラを表示し、住人2人の会話では住人の立ち絵・表情を保持する。感嘆符だけで怒りにはしない。音声生成・既存セリフの変更は行わない。

`?preview=manager` は通常セーブと独立した表示確認。`&pose=happy` 等でポーズを指定できる。一時停止を解除すると掃除アニメーションを確認できる。
