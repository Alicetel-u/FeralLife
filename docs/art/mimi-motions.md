# ミミの全モーション（2026-10-29）

内蔵imagegenで、前回のマップ用ミミを基準に日常動作9種と表情9種を制作。日常動作は `assets/characters/rabbit/observation-v1/`、表情は `assets/characters/rabbit/emotions-v2.png`。前回の `map-stand-v1.png` は参照用として保持する。会話用バストアップ・台詞・音声・セーブ形式は変更しない。

日常動作：通常、歩行A/B、座る、眠る、食べる、飲む、掃除、会話。表情：喜び、怒り、悲しみ、驚き、困惑、恐怖、安心、照れ、呆れ。512×512の共通枠、足元(256,492)。全動作に同じ縮尺を適用し、座り・寝姿を立ち姿の高さへ引き伸ばさない。`CHARACTER_ART.rabbit` と `MINI_EMOTION_ART.rabbit` に登録し、共通レンダラーで行動・感情を描画する。歩行Bは足が身体の下を通る通過姿勢に再調整し、踏み出しと区別する。第三幕の街マップでは立ち姿のまま移動し、歩きコマは切り替えない。

`tools/prepare-mimi-art.py --actions <原稿> --emotions <原稿> --passing <歩行通過原稿>` でフレーム登録。生成原稿のRGBを塗り替えず、連結した人物ごとに分離してアルファを保ち、共通の縮尺と枠へ配置する。原稿はローカルのgenerated_imagesに保持し、公開パッケージは使用するゲーム用フレームのみ。確認用は `tests/mimi-visual.html`。
