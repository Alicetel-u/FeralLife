# モク・ルナの観察用ミニキャラ統一（2026-10-18）

感情16種と日常行動の画風が混在していたため、観察用の通常・歩行2コマ・座る・睡眠・食事・飲む・掃除・会話を新16種と同じキャラクター造形でそろえた。会話イベントのバストアップ立ち絵は対象外。

- 画像：`assets/characters/cat/observation-v3/`、`assets/characters/hostess/observation-v3/`（各9枚）
- 感情：両キャラの`emotions-v3.png`（各16種、1536×2048、元の生成原稿から再パック）
- 座標・足元：`src/observation-art.js`。実際の素材を`CHARACTER_ART`に割り当てるので通常・行動・歩行で旧素材へ切り替わらない。
- 品質：96/128pxの行動画像と640×768の感情画像への縮小を廃止。行動は生成原稿の切り抜きを300～450px程度で保持し、感情は元解像度を維持。アルファの整理は事前に実行して、表示中の強いアルファ閾値処理をなくした。Canvasでは最終表示サイズに一度だけ縮小する。

## 生成と処理

組み込みimagegenを使用。参照は採用済みモク16種、ルナ16種。各キャラ1回ずつ3×3の行動アトラスを生成した。

プロンプト：採用済み16種と同じ顔、頭身、線、服装、耳・尻尾を厳密に維持する。モクは黒髪・半眼・白Tシャツ・黒短パン・サンダル、通常と歩行は口のタバコと金色の缶を維持。ルナは金髪巻き髪・黒リボン・赤い瞳・チェック柄の服・黒い靴とバッグ。透明背景、3列3行、順番は通常立ち／左足前の歩行／右足前の歩行／座る／眠る／食事／飲む／掃除／会話。高解像度、各セルで同じ体格、文字・背景・枠・影を追加しない。睡眠と食事ではモクのタバコは消して脇に置く。

パック処理は`tools/prepare-observation-art.py`。連結成分で各キャラを取り出し、画像の行境界をまたぐ髪や足を切らずに保持する。元データのサイズを保ち、低解像度の中間画像は作らない。生成原稿はローカルのgenerated_imagesに保持し、ゲーム用画像だけを公開する。
