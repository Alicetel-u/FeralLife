# 金城 ルナ

25歳の猫獣人。キャバクラ勤務。店では聞き上手、家では昼寝と省エネ。
独立資金を貯めるつもりが、「仕事用」のバッグを買いすぎる。

- 19時から約8時間、夜の店へ出勤。7〜16時は睡眠を優先。
- 出勤前などに無料の廊下相談。起きて在宅している住人のうち、最もストレスの高い相手を訪ねる。
- 相談で相手のストレスが22減り、相互の関係が9改善。ルナは5気疲れする。金銭の移動なし。
- バッグ購入の固有イベント。買い物代と箱が増え、不足分は借金になる。
- 新規ゲームの最初の募集に登場。古い進行中セーブにも候補として追加。満室・終了済みの観察記への強制入居なし。
