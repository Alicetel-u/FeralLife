# 灰田 ネム

モクの7歳下の妹、22歳の猫獣人。雑貨店のアルバイト。
黒とピンクの地雷系ファッション、返信を待ちすぎる癖、兄にだけ辛口な世話焼き。
兄を立て直すためと言わず、家賃の安さを口実に別の部屋へ入居する。

- 入居候補に `sister` を追加。古い進行中セーブでも候補になる。満室なら新たな入居はできない。
- モクとの相互関係は25で開始。入居時に兄妹の会話を表示。
- 12時から約5時間、バイトと買い物へ外出。
- 固有行動「兄の生存確認」では在宅して起きているモクを訪問。兄のゴミが8、ストレスが8減り、ネムのストレスが5減る。関係は相互に6改善。
- モクが外出・睡眠中ならスマホの返信待ちになり、自分のストレスが8増える。兄を起こさない。
- 推しグッズの通販には通常の買い物費用とゴミ増加があり、専用イベントと独り言が出る。
- `?preview=sister` は入居済みの確認用。既存セーブを読み書きしない。
