# BGMの出だし

タイトル・プロローグ・ルナの3曲にあった冒頭の無音のみを短縮。先頭の音を切らないよう約10msの余裕を残してMP3を再エンコードした。

| ファイル | 除いた冒頭無音 |
| --- | ---: |
| title-countdown.mp3 | 約0.488秒 |
| the-midnight-crossing.mp3 | 約0.082秒 |
| luna-odayakana-gogo.mp3 | 約0.099秒 |

音源を先頭1秒・-50dB／40msの条件で再検査し、40ms以上の冒頭無音がないことを確認。他の8曲には同条件の冒頭無音がなかったため変更していない。巻き戻り時計などの演出用の曲は維持。

`createNormalBgm().preload(cue)` は再生を許可せずに、指定曲を一度だけ読み込む。タイトル曲はSTART前に先読みし、その後は選択した曲と直後に使う可能性が高い1曲を準備する。同じ場面の会話送りでload()を繰り返したり、再生位置をリセットしたりしない。STARTによる音声解放、ミュート、音量、一時停止、演出上の無音は既存の条件を守る。
