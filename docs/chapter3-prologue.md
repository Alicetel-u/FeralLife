# 第3幕プロローグ（第1段階）

実装は `src/act-three-prologue.js`。第2幕完了画面の「次へ」、開発メニューの第3幕、`?preview=act-three` が同じ再生処理を使用する。第3幕本編や選択肢は含まない。

専用CGは `assets/events/chapter3/chapter3_prologue_01.png` ～ `09.png`。順に緊急ニュース、迎撃、弾切れ、投擲、爆発、群れ、逃がす会話、抜刀、突撃。画像参照とカメラ・SE・台詞の時刻をショット定義から差し替えられる。

通常メッセージウィンドウを立ち絵なしで再利用。指定された14台詞のみ。新規の有料ボイス生成や既存録音の再生成は実施していない。SEはWeb Audio合成（音設定に従う）。ホワイトアウトでSE停止し、無音を挟んで既存 `rewindTransitionHTML` / `startRewindTransition` の `clockOnly` オプションへ接続する。第1・第2幕の既定動作は変更しない。

進行は既存の幕の記録を保ち `state.actThree` に保存。映画は現在カットの先頭、時計・タイトルは各演出の先頭から復帰。終了後は黒背景の再生終了メニューで止まり、本編に進まない。確認用URLは別の保存キー、開発メニューは通常セーブを変更しない。

## CG生成プロンプト

内蔵image_genを使用。参照画像は既存のルナ、モク、大家（外見参照のみ。ミニキャラ比率は使わず成人の等身へ）。共通指定：16:9、重厚なアニメ塗りのサバイバルホラー映画CG、冷たい青い環境光と暗赤色・炎の反射、同じ廃墟化した日本のアパート廊下。主要人物と動作を中央45%へ寄せ、下25%は会話ウィンドウ用。立ち絵・ミニキャラ・コラージュ・ロゴ・字幕は不可。ニュースのみ「緊急速報」の警告図形。大家は白黒の髪・目のクマ・茶色のセーター・黒いズボン、モクは黒い猫耳と短い黒髪・白いTシャツ・黒いショートパンツ、ルナは金髪の猫耳・長いウェーブヘア・黒いリボン・白黒チェックのドレスを維持。

1. 暗い室内のテレビ緊急放送。ニュースキャスター、世界地図上の各地に赤い警告、オリジナルの放送グラフィック、アナログノイズ。
2. 大家がアサルトライフルを撃ち、近くの背後にいるモクとルナをゾンビから守る。マズルフラッシュ、必死な表情。
3. 弾切れで銃が止まった大家の寄り。構えたライフル、焦りと決意、背景に迫るゾンビ。
4. 大家が廊下に手榴弾を投げる瞬間。二人は背後で身を低くする。まだ爆発させない。
5. 同じ廊下の大爆発。炎、火花、瓦礫、黒煙。主要人物は写さない。
6. 爆煙から現れる無数のゾンビ。残り火と冷たい逆光、絶望的な奥行き。
7. 大家が前で二人を守り、裏口へ逃がそうとする緊迫した会話。背後から群れが迫る。
8. 大家がナイフを抜く決意の瞬間。顔と手、銀色の刃、犠牲を覚悟した表情。
9. 大家が単身、ナイフを手に大群へ突撃。後方斜めからの動的な構図、煙の先の光。
