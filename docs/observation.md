# 第一幕の生活観察

部屋ではモクの独り言、建物の前と廊下では大家との会話を表示する。メモ収集・調査ボタン・メモ保存は廃止。旧セーブに残るメモ項目も読み込み時に除去する。

開始は既存導入と一致する17時。灰皿の相談は23時に変更し、片づけ、建物前への往復と大家との会話、帰宅後のテレビ、灰皿の異変を経てから発生する。料理の相談は翌日13時、結末は3日目9時を維持する。

会話中は時計を止め、外での会話はモクが該当場所に到着してから開始する。既読区間は早送りできる。会話カーソルは保存し、巻き戻し後も既読を引き継ぐ。追加音声生成は行わない。

`npm run dev` 後、`?preview=observation` で通常セーブと独立した一時停止プレビューを開ける。検証は `npm test` と `npm run build`。
