# 第一幕の生活観察

14場面・42行の掛け合いを `src/act-one-observation.js` から表示する。既存イベント、選択肢、失敗・成功の結末、発生時刻は維持する。

- 灰皿の相談前：座る場所 → 換気 → テレビ → 灰皿の異変。
- 料理の相談前：事件後の会話 → テレビ → 夜更かし → 朝 → 片づけ → 空腹と眠気。
- 解決後：休息 → 廊下 → 静かな夜 → 朝。

会話中はゲーム内時計を止める。未音声の行は最低3.6秒を確保して自動送りし、「次へ」で手動送りできる。「見る」で調べた行は手動送りまで保持し、メモ一覧やメニューを開いている間も自動送りを止める。調べた内容は観察カードとMENUの日誌から読める。

既読・メモ・現在の行をセーブする。巻き戻しでは既読とメモを引き継ぎ、その区間を全部見ていれば早送りできる。旧セーブは過去時刻の場面を再挿入せず、その先から続く。第二幕の進行には適用しない。

追加会話の音声は未生成。全幕用音声抽出の act1/all にゲームデータから含めるが、従来の intro 範囲や既存音声は維持する。

`npm run dev` 後、`http://localhost:4173/?preview=observation` で一時停止した観察プレビューを開ける。通常プレイとは別の保存領域を使う。

検証：`node --test tests/*.test.mjs`、`npm run build`。ブラウザでは導入から観察・事件への接続、調べる、手動送り、セーブ復帰、390px/1280pxの表示を確認する。
