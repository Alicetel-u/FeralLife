# 第一幕の生活観察

観察用のカード型UI・メモUI・専用送りボタンは禁止。観察セリフは既存の吹き出しだけで表示する。部屋ではモクの独り言、建物の前と廊下では大家との会話を表示する。メモ収集・調査ボタン・メモ保存は廃止。旧セーブに残るメモ項目も読み込み時に除去する。

開始は既存導入と一致する17時。灰皿の相談は23時に変更し、片づけ、建物前への往復と大家との会話、帰宅後のテレビ、灰皿の異変を経てから発生する。料理の相談は翌日13時、結末は3日目9時を維持する。

会話中は時計を止め、外での会話はモクが該当場所に到着してから開始する。既読区間は早送りできる。会話カーソルは保存し、巻き戻し後も既読を引き継ぐ。追加音声生成は行わない。

`npm run dev` 後、`?preview=observation` で通常セーブと独立した一時停止プレビューを開ける。検証は `npm test` と `npm run build`。

## 観察パートの正式な区分（2026-10-24確定）

「観察パート」はプロローグ・トラブル・エピローグの間にある通常の生活観察区間を指す。同じ区間に会話イベントが複数あっても、観察パートは1つと数える。BAD END後のタイムリープ・再挑戦は新しい観察パートとして数えない。以下の名称をシナリオ制作・実装・デバッグの共通用語とする。

| 正式名称 | 開始 | 終了（直前） |
| --- | --- | --- |
| 第1幕・観察パート1 | 第1幕プロローグ終了後 | 第1トラブル「灰皿がもう限界ニャ！」 |
| 第1幕・観察パート2 | 第1トラブル解決後 | 第2トラブル「寝不足なのに料理すんな！」 |
| 第1幕・観察パート3 | 第2トラブル解決後 | 第1幕エピローグ |
| 第2幕・観察パート1 | 第2幕プロローグ（ルナ入居）終了後 | 第1トラブル「夕暮れの待ち伏せ」 |
| 第2幕・観察パート2 | 第1トラブル解決後 | 第2トラブル「嘘つきルナを守れ！」 |

これは区分・呼称の定義であり、既存イベントの発生時刻、進行条件、会話、演出、セーブ挙動を変更する指示ではない。トラブルの選択肢・BAD ENDの演出は観察パートに含めない。
