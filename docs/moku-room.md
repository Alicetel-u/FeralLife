# 灰田モクの部屋

入居中のモクの部屋だけ、共通の四角い間取りの代わりに `assets/rooms/cat/interior.png` を敷く。部屋番号ではなく住人の種類に紐づく。画像が読めないときは従来の間取りに戻る。

絵は移動と同じ173×113の室内座標で描き、表示時に拡大する。次の足元は変えていない。

| 行動 | 足元 |
| --- | --- |
| 睡眠 | (48, 92) 床の布団の上 |
| テレビ | (105, 104) テレビ台の手前 |
| 食事・飲酒 | (82, 104) 低いテーブルの手前 |
| 窓辺 | (65, 94) |
| 冷蔵庫 | (137, 98) |

カーテンは指一本ぶんだけ開き、テーブルには灰皿・空き缶・カップ麺がある。壁のカレンダーに文字は入れない。テレビを見ているあいだだけ画面を点滅させ、ゴミの量に応じて床の空き缶を足す。夜と睡眠中は部屋全体を暗くする。

他の住人の部屋は、同じ座標に絵を足せば個別にできる。再描画は `python tools/paint-moku-room.py`。
