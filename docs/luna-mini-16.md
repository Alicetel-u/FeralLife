# ルナのミニキャラ16差分

元のミニキャラと承認済み立ち絵を参照し、25歳のルナの金髪・巻き髪・黒いリボン・チェック柄衣装・金のアクセサリー・黒いバッグを引き継いだ差分をimagegenの組み込みツールで制作。

## パターン

`assets/characters/hostess/emotions-v2.png` は640×768 RGBAの4列×4段アトラス。順序は以下。

1. happy / angry / sad / surprised
2. confused / scared / relieved / shy
3. furious / panic / despair / pleading
4. stunned / laughing / flirt-wink / flirt-lean

誘惑は2種類。`flirt-wink` は片目を閉じた営業スマイルと手招き、`flirt-lean` は両目を開けて身を寄せる甘えた仕草。元の服装を保ち、表情・視線・重心・手・耳・尻尾で違いを出す。

目は両目を開けた差分13種、両目を閉じた差分2種（安心・大笑い）、ウインク1種に調整。

## ゲームでの使用

`src/mini-emotions.js` の `LUNA_MINI_DIRECTIONS` が既存台詞を完全一致で指定。ハート記号、お願い、謝罪だけを根拠に誘惑を推測しない。第二幕の追跡・契約・逃走場面には誘惑を割り当てない。

観察モードの第二幕の日常会話では「モクちゃん、それ毎日言ってない？」でウインク、「ふふ。じゃあ、少しだけ休もうかな。」で身を寄せる差分を使う。既存の章の台詞・日常台詞にも対応を付けてある。台詞本文、voice用のemotion、会話バストアップ、進行・セーブ形式は変更しない。

個別の台詞で明示する場合は `{speaker:'hostess',text:'...',miniEmotion:'flirt-wink'}` のように指定できる。存在するフレームだけを受け付ける。歩行・睡眠は既存の専用ポーズを優先。未ロード・読み込み失敗時は既存の基本画像へ戻る。OSの動きを減らす設定では追加の揺れを止める。

既存の開発用ルナ確認モードで `?preview=hostess&miniEmotion=flirt-wink` または `flirt-lean` 等の登録名を指定すると、ゲーム本体の描画で確認できる。通常プレイには選択UIを追加しない。

## サイズと制作記録

画像は1枚にまとめ、発話中も同時に描画するのは1フレームだけ。画像展開時の画素容量は1,966,080バイト（約1.88MiB）。全身差分を生成解像度のまま16枚読み込まず、共通縮小率と足元で切り出している。

生成プロンプトは `docs/luna-mini-16-prompts.json`。元の8差分アセットは保持し、ゲームの参照だけをv2へ切り替える。

## 検証

全16フレームの境界と透明PNG、二つの誘惑差分の区別、既存台詞からの16パターンへの到達、シリアスな場面で誘惑しないこと、第二幕の実際の会話進行から両誘惑へ到達すること、歩行・睡眠・未ロード時のフォールバック、描画によるセーブ非改変をテストする。


## モクも観察側へ統合

モクの承認待ち候補として作り直した16種も、今回の追加指示で `assets/characters/cat/emotions-v2.png` として観察モードへ統合した。タバコ・酒の缶・半目・白い服・短パンを引き継ぎ、追加の8種は furious / panic / despair / pleading / stunned / laughing / exasperated / rejecting。画像はルナと同じ640×768で、既存の歩行・睡眠を優先する。本文・バストアップは変更しない。

`MOKU_MINI_DIRECTIONS` で既存の第一幕の台詞に強い感情を指定。`?preview=observation&miniEmotion=furious` 等でゲーム本体のモクを確認できる。モクの生成記録は `docs/moku-mini-16-prompts.json`。

両アトラスは不透明な本体の連結領域を基準に切り出し、隣セルの断片を避けた。描画はキャッシュしたアルファテストで薄い生成マットを除き、RGBは変えない。処理は画像ごとに初回だけ行う。

最終検証：全194テストとビルドが成功。ブラウザでルナの誘惑2種とモクの激怒を観察画面に表示し、描画エラーがないことを確認。
