# 全キャラクターのミニ感情差分

2026-10-17。住人11人・大家・金満トクゾウの13人に、喜び／怒り／悲しみ／驚き／困惑／恐怖／安心／照れの8差分（合計104）を追加。

## アセット

`assets/characters/<type>/emotions-v1.png` は640×384のRGBAアトラス。既存画像は上書きせず、imagegenの組み込みツールで作成した。8人は承認済みミニキャラ画像を参照し、仮スプライトだったミミ・ウル・ゴロ・チリ・ポンは既存の色・服装色・人物紹介に沿って制作した。新しい外見から物語上の設定を追加しない。

生成プロンプト一式は `docs/mini-emotion-prompts.json`。既存8人は本人の画像、新規5人はモクの画像を画風のみの参照として使用。透過を維持した切り出し・縮小・配置だけをPillowで行った。元画像はローカルの `.local/mini-emotion-sources/` に保持。

セル順は上段が happy / angry / sad / surprised、下段が confused / scared / relieved / shy。各キャラ内の縮小率を共通にし、足元を揃えてある。ランタイムは `src/mini-emotions.js` のクロップ座標を使う。アトラス合計は約4.6MB、既存のアイドル読み込みと単体HTML／Pagesパッケージに対応。

## 動作

- 台詞の明示感情、初回火災の演技指定、既存の章別感情指定を優先。感嘆符だけで怒りを推測しない。
- 通常の台詞では安心・困惑・恐怖などの語句も補助に使う。日常では口論・強いストレス・強い眠気に反応する。
- 聞き手は発話が終わってから2.4秒まで直前の感情を保つ。新しい通常台詞で強い感情を解除する。
- 喜び・怒り・困惑・恐怖に控えめな動きを付け、キャラごとに速さと強さを変える。動きを減らすOS設定では追加の動きを停止。
- 既存の歩行フレーム・寝姿・生活ポーズを優先し、生活中は会話の発話時だけ感情ポーズへの切り替えを許可する。新規5人にも食事や買い物等の小物を維持。未ロード時は既存画像／仮スプライトへ戻る。
- セーブ形式・台詞本文・入居候補の制限・イベントのメッセージウィンドウは変更しない。感情差分は観察画面のミニキャラ用で、会話のバストアップとは別。

## 確認

13アトラスの透明背景・全104セルの画像差・境界・足元を確認。追加テストで対象13人の網羅、台詞指定の優先、聞き手の保持と解除、歩行／食事／睡眠時の優先、画像未ロード時のフォールバック、動きを減らす設定とセーブ非破壊を検証。ブラウザの一覧とゲーム本体で描画を確認。

最終確認：全174テスト・ビルド・Pages用パッケージ作成が成功。
