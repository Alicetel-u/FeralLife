# 会話の改稿

モクは29歳の姉、ネムは22歳の妹。セーブに保存される行動ID `checkBrother` は互換性のため維持し、画面上の呼称は「姉の生存確認」に変更した。

24件のトラブルを、具体的な被害、言い返し、傷ついた理由、本音の順で書き直した。全72通りの大家の回答は、選択直後に両住人の反応とその場のオチが続く。沈黙や距離を取る仕草は短い地の文で示し、台詞ごとに感情を指定する。時間経過による結果報告は別の記録であり、その場のリアクションを先送りしない。

モクの開始・日常・訪問・外出・家賃の台詞と、他の住人の固有会話も改稿した。通常の新規開始と「はじめから」は会話を自動で開く。新しく発生した台詞付き日常イベントも会話の表示対象に含める。確認用プレビューでは冒頭イベントを自動表示しない。

事件ID、選択ID、数値効果、発生条件と連鎖は維持。旧セーブの未回答相談は narrativeVersion 3 に更新し、資金・時間・住人をリセットしない。過去に完了した日誌は当時の記録として残す。

検証：`tests/narrative.test.mjs` は全72回答がその場で両者の反応を返すこと、感情の保存、旧相談の更新、姉妹の呼称を確認する。`tools/preview-dialogue.mjs` は開始・再開始、三つの回答、姉妹の反応、スマホ表示、LOG、生成済み単体版を非表示ブラウザで確認する。スクリーンショットは `docs/dialogue-preview/`。
