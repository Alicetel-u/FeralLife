# 採用済み：V3寄せのV4

2026-10-30、ユーザーが比較試聴後「V3寄せ採用、これからはその設定のV4で作っていきます」と決定。

今後の生成設定は `config/voice-generation-defaults.json`。`tools/voices.mjs` が自動的に読み込む。過去の `config/voice-performance.json` は既存キャッシュ・台詞キー検証のため保持するが、新規生成では採用設定を優先する。

- モデル：Eleven v4。
- stability：0.5、similarity_boost：0.85。v4非対応のspeed/styleは送信しない。
- 大家：Haru。気だるい間、乾いた受け答え。緊急時は抑制した明瞭な指示。
- モク：Yoko Honda。脱力した猫の軽口、伸ばす語尾。驚きも聞き取れる声。
- ルナ：Tsuyuri。甘いからかいと笑みを含んだ小悪魔的な語尾。緊急時は驚きや危機感を維持。
- ミミ：承認済みHina。子供っぽく無邪気で可愛い声。通常・恐怖の2設定を維持。

基準となる生成入力は採用時の比較6本とミミの承認済み2本と同じ演技タグ・声ID・設定。台詞ごとの崩落・悲劇・逃走では明示済みの驚愕・恐怖を重ね、喜劇や誘惑に変えない。囁き・ぼそぼそ声にはしない。

採用は今後の生成に適用。既存の本編録音は今回再生成せず、マニフェスト・台詞キー・OK/NG判定を保持した。未収録分の生成は `--only-missing`、既存録音の差し替えは別途明示された範囲だけで行う。指摘音声の修正には `repairReview: true` と具体的な `repairComment` を設定する。

V3寄せとはV4で話し方を寄せたユーザー採用済み設定を指す。V3へのモデル切替、V3録音を使った再学習や完全な声質一致を意味しない。
