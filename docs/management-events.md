# 管理人の相談イベントと会話画面

更新：2026-10-10。日常のブラックコメディを中心に、住人別18案と組み合わせ6案を実装。

## 遊びの狙い

面白さの中心は「解決したはずの小さな事件が、別の住人の暮らしに返ってくる」こと。火災を大事故の一発抽選にせず、焦げ臭い座布団から相談が始まり、修繕・仮住まい・缶の取り違え・冷蔵庫の騒動へつながる。費用を出す、境界を決める、本人に任せる、それぞれの後始末を描く。

観察と入居の選択は継続。住人を直接操作するゲームへは移行していない。相談は一度に一件で、当事者の二人が入居してから相談が届く。「管理人室」または画面下の便りから開く。返事は保留でき、時間切れによる追加被害はない。明示的に「本人に任せる」と答えたときの後日談は、保留とは別。

返事の後は原則16ゲーム時間あけて次の相談。必要な住人、日付、前の相談への返事で登場を判定。未回答の相談は日誌が240件に達しても保護する。17日目8時以降は新たな相談を出さず、18日目9時で現在の状態から結末判定。まだ届いていない後日談は結末画面に件数を表示し、未来の結果を勝手に確定させない。

## 観察画面に重ねる会話表示

参考画像に合わせ、観察画面を背景として左右に大きな立ち絵を重ねる。黒い半透明の下部メッセージウィンドウに金の縁・肉球とハートの装飾・猫耳付きのピンクの名前欄を付け、選択肢は右側の丸いボタンで表示する。既存の観察UIの装飾は引き継がない。会話中は時間を停止し、通常の操作UIと自動会話を隠す。閉じると観察に戻る。

下向きの矢印または本文クリックで進める。AUTOは自動会話送り、SKIPは選択肢の直前まで進む。どちらも仲裁の返事は選ばない。LOGで履歴、HIDEで立ち絵だけの表示、MENUで前のセリフや観察へ戻れる。装飾・アイコンはSVGで描き、OS依存の絵文字を使わない。二人の住人がいる相談では、管理人の発言中も二人の立ち絵を維持する。管理人の架空の立ち絵は置かない。数値は仕様検討中の仮値として、選択肢の横には表示しない。

スマートフォンでは立ち絵を拡大して左右を一部トリミングし、下部の会話領域を確保する。日誌の通常イベントも同じ表示で読み、元の文章を保持する。

## 住人同士の仲裁イベント

全24件を二人の住人の対立として構成。喧嘩を中心に、相談・心配・善意のすれ違いも扱う。当事者双方の言い分を聞き、管理人は場所・時間・責任・公開範囲などを調整する三択で仲裁する。正解／放置／悪ふざけという固定の並びにはしない。即時の反応に加えて、全選択に後日談があり、収まった不満と残った負担を描く。効果の数値は仮値。

例：モク×ルナの煙と香水、ホロ×アンの深夜騒音、ネム×ペコの立替金、ルナ×ネムのバッグ疑惑、モク×ホロの仮住まい。恋愛・妊娠の生活相談は初期OFFを維持し、本人の意思を尊重する。

内部のイベントIDと選択IDは維持。旧版の未回答相談は双方が入居済みなら会話を更新し、相手が未入居なら入居まで保留する。過去の決断と結果は保持する。
## 管理資金と結末

初期管理資金¥22,000、安全70、管理人への信頼50、話題0。毎日の家賃入金を管理資金にも加算。維持費は毎日¥1,800＋入居者1人につき¥300、安全は日ごとに1低下。住人の家賃・所持金・借金とは別の帳簿。資金が負になると管理負債になり、結末までに立て直せる。

管理人室で幸福度とご近所の仲も見える。幸福度は空腹・眠気・ストレスから、ご近所の仲は住人間の関係から算出。数値を二重に管理しない。助け合い、小さな仕事の成功、修繕は選択と後日談で記録。

3件以上返事をした場合、以下の順で新しい結末を優先。該当しない場合や観察だけの場合は、従来の結末条件を使用。

| 結末 | 条件 |
| --- | --- |
| 管理人の財布だけ、退去しました | 管理資金が負 |
| 全員、鍵を返す前夜 | 安全25以下 |
| 家主は、ご近所だった | 小さな成功3以上・資金¥60,000以上 |
| 住める炎上スポット | 話題65以上 |
| ろくでもない、助け合い | 助け合い8以上・信頼60以上・安全60以上・ご近所の仲40以上 |

「大富豪」は一回の大会で突然億万長者にせず、複数の小さな仕事を持ち寄って、住人が大家候補になる結末にした。崩壊は見守りの終了時の退去前夜として描写し、途中で住人を操作して退去させる機能は追加していない。

全53テスト成功。単体版46画像内蔵。実ブラウザの操作、画像読み込み、狭い画面の横あふれ、単体版の選択を確認し、警告・実行エラーなし。

`play.html?preview=events&case=roomshare` または開発URLの同じクエリで、全員が入居した一時停止の確認画面。管理人への便りを開けば会話を確認できる。このモードは保存しない。`case=`には表の内部IDを指定できる。

ローカルの `イベント確認.html` をダブルクリックしても、この確認画面をすぐ開ける。
