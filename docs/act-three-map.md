# 第三幕：街マップとミミとの出会い

2026-10-28 のユーザー指定を実装。参照は `docs/story/master-plot.md` と、チャット「けもの荘プロローグ制作」で提示された出発〜ミミとの別れの台本。

## 再生範囲

プロローグ → 時計 → タイトル → 既存の廊下・武器確認 → 出発の会話 → 交差点 → ゾンビの群れを避ける裏道（配送トラック爆発）→ コンビニ → ミミに二階の鍵を渡して別れる → 長距離のゾンビ街路 → 脱出地点・橋 → モクとルナの突然の崩落 → 時計へ強制巻き戻し → コンビニの死に戻り専用シーン。

橋は現在プレイ可能。コンビニからの道中には自動の移動演出のみ追加し、新しい選択肢や会話は挟まない。橋では会話の後、二人が予兆なく倒れ、大家「…………え？」からタイムループする。倒れる原因などの未確定事項は追加していない。

## 表示と操作

- 俯瞰の街一枚絵を採用せず、個別の透過ランドマークを横方向に並べる。
- けもの荘は `assets/apartments.png` の二階建て・三室ずつの緑の扉・右階段・屋上水槽・左看板を参照。
- 赤・黒・クリームの簡単な背景。大きなランドマークに大きな三人を重ねる。経路一覧・点線道路・街シルエットは画面に出さない。
- 大家の `matched-v3/idle.png` とモク・ルナの既存ミニキャラをマップ専用の白フチで表示。歩行素材を変更せず、滑る移動と軽い傾き・上下動を使う。
- 交差点のゾンビはカウントダウン後に出現。会話を読み終えると「裏道から回避する」が選べる。裏道到着後はトラック爆発会話を必ず再生し、爆発の台詞に合わせて白フラッシュ・揺れ・黒煙を表示する。会話終了までコンビニへの移動を禁止する。
- 台詞は `eventStageHTML` と既存の名前欄・話者色・ウィンドウCSSを使用。独自の下部「前へ／次へ」は使わず、通常会話と共有する矢印ボタン・本文タップで進む。戻る・AUTO・SKIP・履歴・表示切替・音設定は標準の歯車メニューから操作する。長い台詞は既存の `messagePages` でページ送りする。
- マップ用BGMとミミ用BGMを使用。新しい有料音声生成や既存音声の再生成は行っていない。

## 保存と確認

`state.actThree` の `mapStoryRevision:3`、`mapStep`、`mapScene`、`mapCursor`、`mapPage`、`mapSeen`、`mimiKeyGiven` に保存。移動途中は出発側の地点、会話途中は現在の台詞・ページから再開する。古いマップ試作セーブは新しい出発会話から再開し、新設の会話を飛ばせない。

確認URLは `?preview=act-three-map`。`scene=departure|crossing|detour|store|farewell|bridge|return` で実際のシナリオ状態から確認できる。`silent=1` を付けると、その確認画面だけBGM・音声を鳴らさない。プレイヤーの通常ボイス設定は変更しない。開発メニューにも同じ場面別の入口があり、通常セーブは変更しない。

`tests/act-three-map.test.mjs` と `tests/act-three-story.test.mjs` で順番、会話中の移動禁止、一時停止、途中再開、鍵の授受、橋での強制ループを検証する。

## 裏道トラック爆発（2026-10-29）

交差点の群れとは異なる危険として、裏道に放置された配送トラックが突然爆発。大家が腕時計を確認して二人に立ち止まるよう命じた直後の爆発で三人は無傷。大家が「……前は、ここで失敗したからな」と口を滑らせる。新たな鍵・食料・武器の回収は行わない。爆発は CSS のトラック、白フラッシュ、画面揺れ、黒煙で演出。専用会話の `detour` は `src/act-three-story.js`、制御は `src/act-three-map.js`。旧 revision 1 の裏道到着セーブは新イベントから再開し、すでにコンビニ到着済みの場合は既存の会話位置を維持する。

## コンビニから橋までの長距離移動（2026-10-29）

ユーザー指定でコンビニと橋の横方向の距離を他区間の **2.6 倍**に拡大。移動時間は通常 **8.4 秒**（他区間 2.4 秒、動き低減設定は 4.2 秒）。ランドマークの総数やセーブ位置は変更せず、移動進行だけワールド座標へ変換する。

既存ゾンビ素材を再利用し、コンビニ〜橋の路面に四組のゾンビ計10体、バリケード2か所、路面の瓦礫・ひびを配置。すべて背景側にあり、戦闘や追加のセリフ・ループ原因の説明を発生させない。移動中は街並みが連続して流れ、移動の一時停止時はゾンビの揺れも止める。橋での既存台詞、倒れる瞬間、時計演出、コンビニへの死に戻りは維持。

`actThreeMapWorldPosition` / `actThreeMapTravelDuration` と `.map-bridge-route` で実装。`tests/act-three-map.test.mjs` では座標・秒数・ゾンビ配置を、`tests/act-three-story.test.mjs` では長距離通過後の橋とループの進行を確認する。

## 交差点→裏道→コンビニのL字移動（2026-10-29）

街マップは単純な右スクロールではなく、交差点までは右、交差点から裏道へは上、裏道のトラック爆発イベント後にコンビニへ右折するL字型。交差点のゾンビは下の表通りに残り、三人は壁に挟まれた裏道へ上って回避する。上への移動は横移動なしのワールド座標とカメラの縦スクロール、三人の一時的な上昇モーションで表現。道路・壁・進行方向の三角マークとコンビニへの横道をCSSで追加。

`actThreeMapWorldPosition` はX座標、`actThreeMapVerticalPosition` は上り区間のY進捗。縦スクロール量は表示領域の高さに基づき、リサイズ時に再計算。移動時間は交差点→裏道が通常3秒、既存のコンビニ→橋は8.4秒を維持。一時停止時はカメラと三人の位置を固定し、再開時に続きから進む。セーブ状態の地点番号・会話進行・裏道爆発・コンビニ・橋・死に戻りは変更しない。

確認は `?preview=act-three-map&scene=crossing` で交差点のイベント後、↑の移動→裏道爆発→→のコンビニまで一続きで行う。
