# 空腹 ペコ

23歳の猫獣人。パン屋の短時間バイト。給料より先に胃袋が予定を立てる大食い。
所持金300円で入居し、食費のせいで家賃が足りなくなる。

- 入居候補の内部キーは `peko`。古い進行中セーブにも候補を追加。
- 毎時の空腹増加は16（通常6）。食事を好むが、睡眠などの欲求も優先度に従って処理する。
- 食事時の所持金が900円以上なら900円の大盛りで空腹65減少。
- 900円未満なら200円の特売弁当で空腹38減少。不足分は既存の仕組みで借金となる。
- 食べるたびに容器などのゴミが4増える。専用イベントと台詞を表示。
- 日収1800円、家賃1200円。10時から約4時間、パン屋のバイトと特売探しへ外出。
- `?preview=peko` で入居済みの確認画面。既存セーブを読み書きせず、一時停止で開始。
