# 観察モードの自動コメディ演出

プレイヤーの操作は不要。既存の観察台詞の行と経過秒に同期して、準備・空振り・オチをポーズ、短い移動、小物で見せる。観察の台詞・音声・所要時間・事件の発生時刻は変更しない。

- 第一幕：缶をどかして座れば片づけ終了、灰皿の山を崩す、持ったスマホを探す、動画を見始める、空腹、起きかけて寝直す、朝の片づけを座って考える。
- 第二幕：荷ほどきで靴がバッグから飛び出す、掃除の満足と残った片づけ、手ぶらの挨拶、お茶の後に洗い物を避けて寝たふり、外出前の持ち物確認。

`src/observation-comedy.js` は既存の `actOne.observation.current`（id/index/elapsed）から表示だけを計算する。新しいセーブ項目、入力、乱数、常駐タイマー、追加音声は使わない。再開・一時停止・音声待ちでも会話と同じ場面を保つ。片づけの終了とお茶の寝たふりは、直後に元の行動へ戻ってオチが消えないように保持する。

住人の論理座標や移動経路を変更せず、室内レンダラーと吹き出しが同じ表示座標を使う。通常の移動中は歩行を優先し、大家の統一スプライトは変更しない。小物は既存の絵を描き替えずCanvasの小さな形で補う。動きを減らす設定では途中移動と傾きを抑え、ポーズとオチは残す。

## 夜更かしと熟睡の時間経過（2026-10-24）

夜更かしは約8.4秒で深夜から夜明け・昼へ。既存のテレビの照り返しと4段階の独り言を保つ。熟睡は約6.8秒で、寝姿を1.2秒見せ、4.5秒で夜を送り、朝の光を約1.1秒見せてから起床する。終端の待機中は次の行動の直前に時計を留め、寝姿や次の台詞を先走らせない。

大きな時計は両方とも画面の上から32dvhの位置。キャラの手前に時刻を重ねず、観察カードは演出中だけ隠す。夜の色と朝の光は観察画面のみに重ねる。操作メニューや一時停止中は進行を止め、演出の経過時間を保ったまま再開する。セーブ形式・トラブル・廊下での遭遇動線は変更しない。

朝の区切りは3日目7:00（hour=55）に統一。熟睡の早送りはその時点で終了し、ベッドで目を覚ましたモクの2セリフをボイス付きで再生する。「朝の空気を吸ってくるニャ。……ついでにタバコもニャ。」の後に、従来の廊下での大家との遭遇へ進む。起床後は無言時間の自動倍速も解除し、室内・廊下の動きを通常の観察速度で見せる。

## 第二幕・観察パート1の逃げ込み会話（2026-10-24）

従来の独立した5小話を、ユーザー承認済みの31台詞の一続きの会話へ差し替えた。大家に手伝いを頼まれる→102号室へ逃げ込む→ルナも手伝いを勧める→外の大家に捕まる→ルナだけ買い物へ向かう。旧5IDは会話の節目として維持し、セーブとデバッグの移動先を保つ。会話は夕方、既存の18時の玄関トラブルの直前に連続して流れる。

表示座標は台詞と経過時間から計算し、モクの方向転換・逃げ込み・後ずさり・廊下への退出、ルナの玄関への接近とバッグ、大家の廊下での待機を見せる。部屋・外観・吹き出しの座標を同期する。会話の節目の待機は0.08秒。ボイス中は次へ進めず、声がない場合も読める時間を確保する。通常速度6では第二幕の無言の時間だけを早送りし、廊下を歩くモクの速度制限は維持する。
