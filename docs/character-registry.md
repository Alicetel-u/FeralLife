## 管理ルール

1. 番号は二桁のキャラクター固有番号として永久固定し、入居部屋番号とは分ける。
2. 名前・種族・属性を独立した項目として管理する。
3. 属性はキャラを象徴する要素（タバコ、酒、浪費など）とし、種族と混同しない。
4. 「専用画像あり」は `src/character-art.js` に正式な個別キャラ画像が登録されていることを指す。仮ドット絵は数えない。登録されていることと実ファイルの存在・正常表示の検証は別。
5. 新規キャラは08から順番に採番し、一度割り当てた番号を再利用しない。
6. 画像の追加・差し替え時には管理表の状態も更新する。
7. 既存の内部IDはセーブ互換性のため無断で変更しない。03・酔田ホロの内部IDが `fox` なのは旧キャラ置換の名残。
